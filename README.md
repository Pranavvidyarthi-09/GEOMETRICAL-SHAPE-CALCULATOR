# Geometric Shape Calculator

## Overview

The **Geometric Shape Calculator** is a Python-based console application that performs mathematical calculations for different 2D and 3D geometric shapes. It calculates values such as area, perimeter, volume, surface area, and other related measurements.

The project also includes input validation, formula display, random shape suggestions, date and time display, and calculation history.

## Features

* Supports 12 geometric shapes.
* Calculates area and perimeter for 2D shapes.
* Calculates volume and surface area for 3D shapes.
* Displays the formula used for each calculation.
* Validates user input.
* Provides random shape suggestions.
* Displays the current date and time.
* Maintains calculation history.
* Handles invalid inputs.

## How to Run

Run the following command:

```bash
python main.py
```

The program will display the list of geometric shapes. Enter a number from **1 to 12**, then provide the required dimensions.

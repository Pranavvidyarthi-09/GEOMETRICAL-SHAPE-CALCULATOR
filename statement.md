# Geometric Shape Calculator

## Problem Statement

Calculating geometric measurements manually can be time-consuming and may lead to calculation errors. This project provides a simple Python-based calculator to quickly calculate measurements of common 2D and 3D geometric shapes.

## Scope of the Project

The project calculates area, perimeter, volume, surface area, and other applicable measurements for 12 geometric shapes. It also provides input validation, formula display, random shape suggestions, date/time, and calculation history.

## Target Users

* Students learning mathematics and geometry.
* Teachers for basic classroom demonstrations.
* Beginners learning Python programming.
* Users who need quick geometric calculations.

## High-Level Features

* Supports 12 geometric shapes.
* Calculates area, perimeter, volume, and surface area.
* Displays formulas used for calculations.
* Validates user input.
* Provides random shape suggestions.
* Displays date and time.
* Maintains calculation history.
* Handles invalid inputs.
